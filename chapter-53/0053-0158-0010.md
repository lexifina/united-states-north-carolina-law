# G.S. 53-158.10. Definitions.
For purposes of this Article, the following definitions apply:
(1) "Depository institution" has the same meaning as set forth in the Federal Deposit Insurance Act, 12 U.S.C. §§ 1811, et seq.
(2) "Hazardous condition" has the same meaning as set forth in G.S. 53-301(a)(23).
(3) "Trust institution" has the same meaning as set forth in G.S. 53-301(a)(52).
