# G.S. 147-86.24. Debtor information and skip tracing.
A State agency shall collect from clients and debtors minimum identifying information as prescribed by the State Controller. A State agency shall use all available debtor information to skip trace debtors as prescribed by the State Controller.
The State Controller shall establish procedures to give the State Controller access to information that is in the custody of a State agency and could assist another State agency in the collection of accounts receivable owed to that State agency. A State agency that has this information shall cooperate with the State Controller in giving the State Controller access to the information. If the information is contained in an electronic database, the State agency shall provide the State Controller on-line electronic access upon request. A State agency is not required to give the State Controller access to information when a State or federal law prohibits the disclosure of the information.
